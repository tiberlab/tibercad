\chapter{Simulation of strain}
\label{chap:strain}
\section{Theory}
The theoretical model of strain simulation can be found in Refs.\cite{strain1, strain2}. The code can compute elastic deformations in a heterostructure and can calculate the deformed shape of the structure. The hetrostructure can be either grown on a substrate or not. External pressure may be applied to a structure as well.
\section{Models section parameters}
The {\bf Models} section looks like follows:
\begin{verbatim}
model macrostrain
{
    options
    {
         simulation_name = strain_in_transistor
         physical_regions = (2, 3, 4)
    }
 }
\end{verbatim}
There are two possible kinds of boundary conditions.
The mandatory keyword 

\textit{type} = \{ substrate $\vert$ pressure \} 

specifies the boundary condition type.
\subsection{Substrate boundary condition}
In this case the boundary condition region is the boundary between the device and the substate. The substrate does not belong to the device. Therefore it is necessary to define 
both the boundary region number and the substrate material (like it is done in sec.~\ref{Device}).
\newtheorem*{subst}{Role of substrate}
\begin{subst}
 In general, the ``substrate'' is a material that defines the lattice matching conditions, and not
 necessarily a real solid body on which the device is grown.
\end{subst}

\begin{verbatim}
BC_Region layer_of_Al_0.3_Ga_0.7_N
{
     BC_reg_numb = 14
     type = substrate
     mat = AlGaN
     x = 0.3
     structure = wz
     y-growth-direction = (1,0,-1,0)
     z-growth-direction = (-1,2,-1,0)
     x-growth-direction = (0,0,0,1)
}
\end{verbatim}


\subsection{External pressure boundary condition}
The parameter \textit{pressure} specifies the value (in GPa)  of the normal pressure applied to the boundary region \textit{BC\_reg\_numb}. 
\begin{verbatim}
BC_Region tip_upon_a_surface
{
     BC_reg_numb = 12
     type = pressure
     pressure = 12.3
}
\end{verbatim}
\newtheorem*{pressure}{Sign of pressure}
\begin{pressure}
 The value of pressure has a positive sign if the external force acts towards the surface, which in general has to be  the  boundary of a simulation environment.
\end{pressure}

\section{Solver parameters}
Choice of the necessary parameters to be put in the section depends on the type of the structure, namely, if it has a substrate or not. 
\subsection{Structure with a substrate}
The only obligatory parameter is  \textit{substrate} that is a name of a substrate boundary condition, e.g:
\begin{verbatim}
strain_in_transistor
{
   substrate = layer_of_Al_0.3_Ga_0.7_N
}
\end{verbatim}

\subsection{Structure without a substrate}
The parameter \textit{substrate} should not be present  but the following parameters should be defined.
\begin{itemize}
\item The reference lattice material
is defined by the coordinates of a point  belonging to this  material, using the parameter \textit{reference\_material\_point}.
\item As it follows from Ref.~\cite{strain1},  additional geometrical points have to be specified, according  to the device dimensionality. The corresponding parameters are:
\textit{fixed\_point1}, \textit{fixed\_point2} and \textit{fixed\_point3}.
\end{itemize}
Example for a 2D simulation:
\begin{verbatim}
 strain_in_transistor
{
  reference_material_point  = (0, 100, 0)
  fixed_point1 = (0, 0, 0)
  fixed_point2 = (10, 0, 0)	 
}
\end{verbatim}
\subsection{Additional parameters}

\subsubsection{Numercal solver parameters}

\textit{tolerance}: relative tolerance of the iterative solver, e.g.
\begin{verbatim}
 tolerance = 1e-10
\end{verbatim}
The default  value is 1e-13.

\textit{ksp\_type} =  type of  solver: \textbf{gmres},  \textbf{bcgsl},  \textbf{bcgs}, \textbf{cg}, \textbf{richardson}.

Default is: 

\textbf{gmres}  for  1D 

\textbf{bcgsl} for 2D and  3D
\\
\textit{pc} =  type of  pre-conditioner :  \textbf{ilu},  \textbf{composite},  \textbf{jacobi}, \textbf{lu}, \textbf{cholesky}, \textbf{eisenstat}.
\\
Default is : 

\textbf{ilu}  for  1D 

\textbf{jacobi}  for 2D and  3D

\textit{max\_iterations}  =  max  number of iterations (default = 1000)

\textit{monitor}, \textit{xmonitor}:  if  \textbf{true},  textual or graphical monitor of convergence process is  enabled (default = \textbf{false})





\subsubsection{Periodic boundary conditions}
It is possible to specify periodic boundary conditions along the coordinate axes. The relative parameters are:

\textit{periodicity\_x} = \{ true $\vert$ false \}

\textit{periodicity\_y} = \{ true $\vert$ false \}

\textit{periodicity\_z} = \{ true $\vert$ false \}

The default value is {\bf false}.
\subsubsection{Mesh refinement}
For the details about mesh refinement refer to the Libmesh library documentation.
The parameter \textit{refinement\_steps } defines number of the refinement steps to be done with default value to be zero. The parameter 
\textit{uniform\_refinement} = \{ true $\vert$ false \} is to choose between uniform and adaptive refinement. The default value is {\bf false}, i.e. adaptive refinement. 
Example:
 \begin{verbatim}
 refinement_steps = 4
 refine_fraction = 0.25
 coarsen_fraction = 0
 max_refinement_level = 10
\end{verbatim}
 

\subsubsection{Deformed shape calculation}
