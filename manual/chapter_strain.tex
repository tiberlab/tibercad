\chapter{Simulation of strain}
\label{chap:strain}
\section{Theory}
The theoretical model of strain simulation can be found in Refs.\cite{strain1, strain2}. The code can compute elastic deformations in a heterostructure and can calculate the deformed shape of the structure. The heterostructure can be either grown on a substrate or not. External pressure may be applied to a structure as well.
\section{Models section parameters}
The {\bf Models} section looks like follows:
\begin{verbatim}
model macrostrain
{
    options
    {
         simulation_name = strain_in_transistor
         physical_regions = (2, 3, 4)
    }
 }
\end{verbatim}
There are two possible kinds of boundary conditions.
The mandatory keyword 

\textit{type} = \{ substrate $\vert$ pressure $\vert$ extended\_material\} 

specifies the boundary condition type.

\subsection{Substrate boundary condition}
In this case the boundary condition region is the boundary between the device and the substrate. The substrate does not belong to the device. Therefore it is necessary to define 
both the boundary region number and the substrate material
% (like it is done in sec.~\ref{Device}).

\newtheorem*{subst}{Role of substrate}
\begin{subst}
 In general, the ``substrate'' is a material that defines the lattice matching
 conditions, and not necessarily a real solid body on which the device is grown.
\end{subst}

\begin{verbatim}
BC_Region layer_of_Al_0.3_Ga_0.7_N
{
     BC_reg_numb = 14
     type = substrate
     mat = AlGaN
     x = 0.3
     structure = wz
     y-growth-direction = (1,0,-1,0)
     z-growth-direction = (-1,2,-1,0)
     x-growth-direction = (0,0,0,1)
}
\end{verbatim}


\subsection{External pressure boundary condition}
The parameter \textit{pressure} specifies the value (in GPa)  of the normal pressure applied to the boundary region \textit{BC\_reg\_numb}. 
\begin{verbatim}
BC_Region tip_upon_a_surface
{
     BC_reg_numb = 12
     type = pressure
     pressure = 12.3
}
\end{verbatim}
\newtheorem*{pressure}{Sign of pressure}
\begin{pressure}
 The value of the pressure has a positive sign if the external force acts towards the
 surface, which in general has to be  the  boundary of a simulation environment.
\end{pressure}

\subsection{Extended device boundary condition}
If device that is grown on a substrate is very large we may want to simulate a part of it only. In this case the simulation domain boundary is not a free surface any more.
The boundary conditions are as follows:
\begin{equation}
   \int C_{ijkl} \frac{\partial u_k}{\partial x_k} n_i d\partial\Omega = 0
\end{equation}
The syntax is as follows:
\begin{verbatim}
BC_Region boundary1
{
   BC_reg_numb = 12
   type = extended_material
}
\end{verbatim}




\section{Solver parameters}
The choice of the necessary parameters to be put in the \textbf{Solver} section depends on the type of the strain boundary condition for the structure, namely, if it is considered as grown on  a substrate or not. 
\subsection{Structure with a substrate}
The only mandatory parameter is  \textit{substrate}, to  which   a name of a substrate boundary condition region has to be  assigned, e.g (referring to the previous example):
\begin{verbatim}
strain_in_transistor
{
   substrate = layer_of_Al_0.3_Ga_0.7_N
}
\end{verbatim}

\subsection{Structure without a substrate (freestanding)}

In this case, the parameter \textit{substrate} should not be present; instead, the following parameters should be defined.
\begin{itemize}
\item The reference lattice material
is defined by the coordinates of a point  belonging to this  material, using the parameter \textit{reference\_material\_point}.
\item As  follows from Ref.~\cite{strain1},  additional geometrical points have to be specified, according  to the device dimensionality. The corresponding parameters are:
\textit{fixed\_point1}, \textit{fixed\_point2} and \textit{fixed\_point3}.
\end{itemize}
Since the elasticity energy is invariant with respect  to  translations and rotations of the structure, then, for the sake of uniqueness of solutions of the equations,  another set of constraints is required.  Hereafter we assume that a mesh is defined over the simulation domain and the displacement field ${\bf u}(\rvec)$ is defined at the mesh nodes. 

 Let $\cal D$ be  the dimensionality of the structure minus the number of directions along which the structure is
 periodic. If ${\cal D} > 0$, then a Dirichlet boundary condition is applied at an arbitrarily chosen  
 node $i_1$: 
\begin{equation} 
{\bf u} (\rvec_{i_1}) = {\bf 0},
 \end{equation}
in order to prevent the structure from  undesirable translations.
In the case of ${\cal D} > 1$, another node  $i_2$ is chosen and a constraint
 \begin{equation}
 ({\bf u} (\rvec_{i_1}) - {\bf u} (\rvec_{i_2}))\cdot(\rvec_{i_1} - \rvec_{i_2}) = 0
 \label{constr2D}
 \end{equation}
is applied, in order to keep the direction between the nodes $i_1, i_2$ unchanged.  If ${\cal D} = 3$, another node $i_3$ is chosen and additional constraint is set:
\begin{equation}
 \left( \rvec_{i_1}- \rvec_{i_2}, \rvec_{i_1} - \rvec_{i_3}, {\bf u}_{i_3} \right) =0,
\end{equation}
so the node $i_3$ has to belong to the $(\rvec_{i_1}, \rvec_{i_2}, \rvec_{i_3})$ plane. 
 





Example for a 2D simulation:
\begin{verbatim}
 strain_in_transistor
{
  reference_material_point  = (0, 100, 0)
  fixed_point1 = (0, 0, 0)
  fixed_point2 = (10, 0, 0)	 
}
\end{verbatim}
\subsection{Additional parameters}

\subsubsection{Numercal solver parameters}

\textit{tolerance}: relative tolerance of the iterative solver, e.g.
\begin{verbatim}
 tolerance = 1e-10
\end{verbatim}
The default  value is 1e-13.

\textit{ksp\_type} =  type of  solver: \textbf{gmres},  \textbf{bcgsl},  \textbf{bcgs}, \textbf{cg}, \textbf{richardson}.

Default is: 

\begin{itemize}
\item 
\textbf{gmres}  for  1D 
\item 
\textbf{bcgsl} for 2D and  3D  
\end{itemize}


\textit{pc} =  type of  pre-conditioner :  \textbf{ilu},  \textbf{composite},  \textbf{jacobi}, \textbf{lu}, \textbf{cholesky}, \textbf{eisenstat}.
\\
Default is : 

\begin{itemize}
\item 
\textbf{ilu}  for  1D 
\item 
\textbf{jacobi}  for 2D and  3D    
\end{itemize}


\textit{max\_iterations}  =  max  number of iterations (default = 1000)

\textit{monitor}, \textit{xmonitor}:  if  \textbf{true},  textual or graphical monitor of convergence process is  enabled (default = \textbf{false})





\subsubsection{Periodic boundary conditions}
It is possible to specify periodic boundary conditions along the coordinate axes. The relative parameters are:

\textit{periodicity\_x} = \{ true $\vert$ false \}

\textit{periodicity\_y} = \{ true $\vert$ false \}

\textit{periodicity\_z} = \{ true $\vert$ false \}

The default value is {\bf false}.

\subsubsection{Mesh refinement}

For the details about mesh refinement refer to the Libmesh library documentation.
The parameter \textit{refinement\_steps } defines the number of the refinement steps to be done (with default value equal to zero). The parameter 
\textit{uniform\_refinement} = \{ true $\vert$ false \} is used to choose between uniform and adaptive refinement. The default value is {\bf false}, i.e. adaptive refinement. 
Example:
 \begin{verbatim}
 refinement_steps = 4
 refine_fraction = 0.25
 coarsen_fraction = 0
 max_refinement_level = 10
\end{verbatim}
 
\subsubsection{Deformed shape calculation}

The displacement field and lattice matching parameters that are found from
master equations can be used in order to define a new shape of the heterostructure. This new shape is the first approximation to the equilibrium one. The next approximations are obtained iteratively by the following steps: at the $n$-th iteration the master equations are solved using the lattice matching deformation $\eps_{ij}^n$ which is defined as
\begin{equation}
\label{eps1}
\eps_{ij}^n = \frac{1}{2}\left(\frac{\partial u_i^{n-1}}{\partial x_j} +
                               \frac{\partial u_j^{n-1}}{\partial x_i}\right)
+ \eps_{ij}^{n-1},
\end{equation}
where the displacement field ${\bf u}^{n-1}$ has been taken from the iteration 
$n - 1$. 
Then the new shape is defined by using the displacements from the last step solution,
and the iterative process is repeated until the displacement field vanishes and additional lattice parameters stabilise. 
The iterative cycle usually converges after 3 - 4 iterations.

The only parameter that controls shape calculation is
\textit{number\_shape\_steps}. The value defines number of iterations. The default value is zero, that means no shape deformation calculation.
