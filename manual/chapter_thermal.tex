\chapter{Heat Balance simulation}

The theoretical model of the heat balance problem can be found in Ref.\cite{wachutka}. 
\section{Heat equation}
The steady state heat equation with the continuity equation reads as

\begin{equation}\label{heat_law}
\nabla \cdot\left(- \kappa \nabla T  \right) = H_S
\end{equation}

where $T$ is the temperature, $\kappa$ is the thermal conductivity tensor and $H_S$ is the total heat source.
The latter term is the sum of the heat sources specified by the submodels described below. The term between the brackets represents the thermal flux $\mathbf{J_q}$.

\section{Physical model}

By neglecting particle effects, the thermal conductivity is only due to the lattice contribution. The lattice thermal conductivity is read from the database.

The thermal model is tagged as \textit{thermal}. In \textbf{options} subsection we indicate the simulation name (\textit{simulation\_name = whatever\_you\_want}) and the simulation domain (\textit{physical\_regions = wherever\_you\_want})


\begin{verbatim}

model thermal
 {

  options
  { 
    simulation_name = whatever_you_want
    physical_regions = wherever_you_want
  }

    ...
}

\end{verbatim}


\subsection{Electron and hole dissipations}


Electron and hole dissipations give the following heat source



\begin{equation}\label{Hs}
H_{S} =-\nabla \cdot \left[(P_n T + \phi_n)\mathbf{J_n} + (P_p T + \phi_p)\mathbf{J_p}\right] 
\end{equation}

where $P_n$ and $P_p$ are the thermoelectric power of electrons and holes, respectively. $\phi_n$ and $\phi_p$ are the electro-chemical potentials.

The equation \ref{Hs} represents severals heat source contributions. Their estimates are reported in table \ref{table:heat_sources}. 

\begin{table}[htb]
\center
\begin{tabular}{l||l}
\textit{Expression} & \textit{Heat source}\\
\hline\hline
$\frac{\left| \mathbf{J_n} \right| ^2}{\sigma_n}$ & \textit{Electron Joule effect}\\
$\frac{|\mathbf{J_p}|^2}{\sigma_p}$ & \textit{Hole Joule effect}\\
$qR_{SRH}\left(\phi_p - \phi_n + T \left( P_p - P_n \right) \right)$ & \textit{Recombination effect}\\
$ -T \mathbf{J_n} \cdot \nabla P_n $ & \textit{Electron Peltier-Thomson effect}\\
$ -T \mathbf{J_p} \cdot \nabla P_p $ & \textit{Hole Peltier-Thomson effect}
\end{tabular}
\caption{Drift diffusion heat sources}
\label{table:heat_sources}
\end{table}





The physical model \textbf{heat\_source} includes a specific source identified by its \textbf{model} name.
Concerning electron and hole dissipations the model is
named \textit{drift\_diffusion\_dissipation}, as reported below.

\begin{verbatim}

   physical_model heat_source
   {		
     model = drift_diffusion_dissipation

     drift_diffusion_simulation = dd_simul_name
   }

\end{verbatim}

In order to include such a heat source we have to use a drift diffusion simulation.

The syntax \textit{drift\_diffusion\_simulation = dd\_simul\_name} allows this connection.




\subsection{Boundary conditions}

By default, thermally insulating surfaces are considered, i.e. 

\begin{equation}\label{TH}
\mathbf{J_q}\cdot \mathbf{N} = 0
\end{equation}

On the opposite side it is possible to include an ideal thermally conducting interface by fixing the temperature to the external one, i.e. : 

\begin{equation}\label{T}
T = T_{ext}
\end{equation}

This condition can be imposed with the following notation

\begin{verbatim}
BC_Regions
{
  BC_Region name_BC_region
  {
    type = heat_reservoir
    BC_reg_numb = 3
    temperature = 300
  }
}
\end{verbatim}

Once a \texttt{BC\_Region}  is inserted in the \texttt{thermal} section, \texttt{heat\_reservoir} is the default \texttt{type}. The default \texttt{temperature} is the one indicated in the solve section.   

Between  such extreme situations, it is possible to take into account a thermally resistive interface, i.e.

\begin{equation}\label{TH}
\mathbf{J_q}\cdot \mathbf{N} = G_s (T - T_{ext})
\end{equation}

where $G_s$ is the thermal surface conductance and $T_{ext}$ is the external temperature.

One can include this condition with the BC type \textbf{thermal\_surface\_conductance}:

\begin{verbatim}
BC_Regions
{
  BC_Region name_BC_region
  {
    type = thermal_surface_conductance
    BC_reg_numb = 3
    g_surf = 0.01
    temperature = 300
  }
}
\end{verbatim}

where \texttt{g\_surf} indicates $G_s$ and \texttt{temperature} stands for $T_{ext}$.

Alternatively, it is possible to indicate the $R_s = 1/G\_s$ quantity i.e. the thermal surface resistance. The notation is


\begin{verbatim}
BC_Regions
{
  BC_Region name_BC_region
  {
    type = thermal_surface_resistance
    BC_reg_numb = 3
    r_surf = 100 
    temperature = 300
  }
}
\end{verbatim}

Furthermore, it is possibile to fix the normal thermal power density  to a  given value $J_{ext}$, i.e.

\begin{equation}\label{TH}
\mathbf{J_q}\cdot \mathbf{N} = J_{ext}
\end{equation}

This condition is set with the BC type \textbf{thermal\_flux}:

\begin{verbatim}
BC_Regions
{
  BC_Region name_BC_region
  {
    type = thermal_flux
    BC_reg_numb = 3
    power_density = 100 
  }
}
\end{verbatim}
