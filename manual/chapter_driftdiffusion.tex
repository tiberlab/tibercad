\chapter{Drift-diffusion simulation of electrons and holes}

\section{Theory}

The semi-classical transport simulation of electrons and holes is based on the drift-diffusion approximation (see e.g.~\cite{selberherr84}).

Beside the electic potential the electro-chemical potentials are used as variables such that the system of PDEs to be solved readds as follows
\begin{eqnarray}
-\nabla(\varepsilon\nabla\varphi - P) & = & -e(n - p - N_d^+ + N_a^-) \nonumber \\
-\nabla(\mu_n n \nabla\phi_n) & = & R \\
-\nabla(\mu_p p \nabla\phi_p) & = & -R \nonumber
\end{eqnarray}
$P$ is the electric polarization due to e.g. piezoelectric effects and $R$ is the net recombination rate, i.e. recombination rate minus generation rate.
The models for the mobilities and the net recombination rates can be specified in the \texttt{physical\_model} sections as described in the following.



\section{\texttt{Models} section}
The \texttt{Models} section looks like follows:
\begin{verbatim}
model driftdiffusion
{
    options
    {
         simulation_name = whatever_you_want
         physical_regions = (2, 3, 4)
    }

    physical_model recombination
    {
      model = model_to_be_used
      ...
    }

    physical_model electron_mobility
    {
      model = model_to_be_used
    }

    physical_model hole_mobility
    {
      model = model_to_be_used
    }
 }
\end{verbatim}

The \texttt{physical\_model} sections can be omitted.
In this case default models are used, namely no recombination/generation for the recombination model and constant mobility for the mobility models.
There can be more than one recombination model.

\subsubsection{Shockley-Read-Hall (SRH) recombination}
The SRH recombination model can be enabled in the input file by specifying
\begin{verbatim}
physical_model recombination
{
  model = srh
  ...
}
\end{verbatim}

SRH recombination is defined as follows:
\begin{equation}
R_{SRH} = \frac{np - n_i^2}{(n + n_i e^{E^*/k_BT})\tau_p +
    (p + n_i e^{-E^*/k_BT})\tau_n}
\end{equation}
$E^* = E_{trap} - (E_c + E_v)/2$ is the trap level with respect to the midband energy. $n_i$ is the intrinsic carrier density, $\tau_n$ and $\tau_p$ are the recombination times.
The parameters are taken from the material database.
The recombination times are dependent on temperature and doping density, e.g.
\begin{eqnarray}
\tau_n & = & \tau_n^0 \left(\frac{T}{T_0}\right)^{\alpha_n} \\
\tau_n^0 & = & \tau_{min,n} + \frac{\tau_{max,n} - 
     \tau_{min,n}}{1 + (N/N_{ref})^\gamma}
\end{eqnarray}
where $T_0$ is the reference temperature (300 K).

\subsubsection{Direct (radiative) recombination}
The direct recombination model can be enabled in the input file by specifying
\begin{verbatim}
physical_model recombination
{
  model = direct
  ...
}
\end{verbatim}

Direct recombination is modeled as follows:
\begin{equation}
R_{direct} = C(np - n_i^2)
\end{equation}
The material data file and the input file use the same keyword \texttt{C} for the parameter $C$.
The database value can be overridden from the input file as described for SRH recombination.



\subsection{Mobility models}

Mobility models have currently to be defined for electrons and holes independently.
The corresponding keywords are \texttt{electron\_mobility} and \texttt{hole\_mobility}, i.e.

\begin{verbatim}
physical_model electron_mobility
{
  model = ...
  ...
}

physical_model hole_mobility
{
  model = ...
  ...
}
\end{verbatim}

The default model is the constant mobility model.

\subsubsection{Constant mobility model}

The constant mobility model (identifier \texttt{constant}) assumes a mobility which depends only on temperature by means of the following formula:
\begin{equation}
\mu = \mu_0 (T/T_0)^{-\gamma}
\end{equation}
In the material data file $\mu_0$ and $\gamma$ have to be specified with the keywords \texttt{mu\_max\_e}, \texttt{mu\_max\_h} and \texttt{exponent\_e}, \texttt{exponent\_h}, respectively.
$\mu_o$ can be ovverridden from the \texttt{physical\_model} section using the keyword \texttt{mu} or from the \texttt{Region} sections using the keywords \texttt{mu\_e} and \texttt{mu\_h}.

\subsection{Boundary conditions}

Boundary conditions are implemented for ohmic contacts, Schottky contacts and free surfaces.
Contacts are boundary models that allow a nonzero normal electrical current.
For this type of boundaries one can define a contact resistance using the \texttt{contact\_resistance} option.
The contact resistance has units $\Omega\mathrm{cm}^2$.
The applied voltage is specified with the option \texttt{voltage}.
A variable can be assigned to this.

The ohmic contact (identifier \texttt{ohmic}) has no further parameters.

A Schottky contact  (identifier \texttt{schottky}) has the additional parameter \texttt{barrier\_height}, which signifies the energy difference between the semiconductor conduction band and the fermi energy in the metal.

The free surface or interface model (identifier \texttt{interface})  currently models surface states in a similar as donors, with the only difference that the density is measured in  $\mathrm{cm}^{-2}$.
The parameters are \texttt{Ns} (density of states), \texttt{Es} (energy with respect to the conduction band edge) and \texttt{g} (multiplicity of the states).

The type of boundary model is chosen by the parameter \texttt{type}, e.g. \texttt{type = schottky}.

\subsection{Unstrained semiconductor model}

The unstrained semiconductor model is the default model.
It can be chosen explicitly by \texttt{model = unstrained}.
It uses a bulk $\mathbf{k}\cdot\mathbf{p}$ model to calculate the band parameters.
The model reads all needed parameters from the material data file.



\subsection{Strained semiconductor model}

The strained semiconductor model is an extension of the unstrained semiconductor model.
It can be switched on by specifying \texttt{model = strained}.
For the calculation of the band parameters it will consider mechanical strain (cf. chapter~\ref{chap:strain}) as calculated from a strain simulation.
As strain can be non-homogeneous, bulk properties are calculated and stored seperately for each element.

The strain simulation can be specified in the \texttt{Physics} section by \texttt{strain\_simulation = <sim\_name>}, where \texttt{<sim\_name>} is the user defined name of the strain simulation.
If omitted, the first available strain simulation will be used.

The \texttt{ksp\_type} specifies the type of Krylov subspace method to be used.
The mostly used methods are
\begin{description}
\item{\texttt{bcgs}} A stabilized version of the biconjugate gradient method. This one works better in 1D than \texttt{bcgsl}.
\item{\texttt{bcgsl}} (default) A modified version of  \texttt{bcgs}.
\item{\texttt{gmres}} Generalized minimal residual method.
\end{description}

The \texttt{pc\_type} specifies the type of preconditioner to be used.
The most useful ones are
\begin{description}
\item{\texttt{ilu}} (default) Incomplete LU factorization. Does not work for materials with high band gap.
\item{\texttt{jacobi}} Jacobi preconditioning (diagonal scaling).
\item{\texttt{composite}} Combination of \texttt{ilu} and \texttt{jacobi}.
\end{description}

The \texttt{ls\_max\_step} parameter defines an upper bound of the $l_2$-norm of the nonlinear line search step.
It should be not too big to prevent the algorithm from diverging, but also not too small to minimize the number of iterations.
Values between 1 and 10 should be a good choice.

The \texttt{nonlin\_step\_tol} defines at which line search step size (in $l_2$-norm) the algorithm stops, i.e. assumes to have reached convergence.
\texttt{nonlin\_step\_tol} is measured in eV.
