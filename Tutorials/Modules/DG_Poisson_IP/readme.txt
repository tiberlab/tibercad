This example shows how to create a simple module.

It has to be compiled using the build_module tool:

> $TIBERCADROOT/bin/build_module module.conf


Implementation Poisson equation by using Discontinuous Galerkin Finite Element Method and considering the classic Interior Penalty Method. 
Reference: D.N.Arnold, F.Brezzi, B.Cockburn and L.D.Marini, UNIFIED ANALYSIS OF DISCONTINUOUS GALERKIN METHODS FOR ELLIPTIC PROBLEMS, Siam j.Numer. Anal., Vol.39, No5, pp. 1749-1779
